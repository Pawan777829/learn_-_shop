# **App Name**: Learn & Shop

## Core Features:

- Unified Browsing: Enable users to browse both products and courses in a single interface.
- Secure Checkout: Process multi-item orders and course enrollments securely.
- Vendor Dashboard: Provide a dashboard for vendors to manage product and course listings, track sales, and manage inventory.
- User Dashboard: Allow users to track orders, enrolled courses, and personal information.
- Personalized Recommendations: AI-powered recommendations engine that suggests products and courses based on user behavior and preferences.

## Style Guidelines:

- Primary color: Forest green (#3B8278) to evoke learning and growth, reflecting the platform's dual purpose.
- Background color: Light sage (#E9E9E4), a very desaturated and bright tone similar to the primary, creating a calm and clean backdrop.
- Accent color: Teal (#3B828F) to highlight interactive elements and important information.
- Body and headline font: 'Inter', a grotesque-style sans-serif, for a clean and modern reading experience.
- Use simple, consistent icons throughout the platform to aid navigation and visual appeal.
- Maintain a clean and spacious layout to enhance readability and usability.
- Subtle transitions and animations to provide feedback and enhance user experience.
